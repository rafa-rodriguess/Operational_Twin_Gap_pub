# Protocol — claim gates

No claim enters the manuscript only because code exited 0.

## Tier 1

Codebook, classification, denominator, human adjudication.

Changes here redefine what a number *means*. Do not freeze SoT claims until Tier 1 items that the claim depends on are closed.

## Tier 2

Derived quantities from frozen inputs (same denominator, same codebook).

Re-runs must cite the frozen input hash / SoT stage id. New splits or new filters are not Tier 2.

## Tier 3

Layout, captions that do not reinterpret, integration of a result already closed.

Do not introduce a new estimator, a new inclusion rule, or a new N in a caption.
